# Production Log

Use this reference when a story video changes after the completed script, or when the final YouTube description must reflect the actual finished video.

Keep the log lightweight. It can live in chat, a handoff note, or a project markdown file. Do not add a new file unless the user asks or the project already has a place for production notes.

## What To Record

Record only changes that affect the viewer experience or the final publishing copy:

- script lines removed, shortened, moved, or left unused
- new scenes, inserts, charts, tables, checklists, captions, annotations, or overlays
- handmade direction that changes emphasis, timing, tone, or chapter structure
- video-AI clips added, replaced, rejected, or shortened
- image or audio substitutions that change meaning, location, character, or mood
- actual chapter names and timestamp candidates noticed during preview
- sources, references, URLs, or claims that must be verified before publishing
- YouTube title, thumbnail, hashtag, or tag candidates that should stay aligned with the finished video

Do not record routine implementation details such as file renames, formatting changes, dependency installs, or temporary render attempts unless they changed the final video.

## Suggested Format

```markdown
# Production Log

## Script Scope
- Video body uses: [A. Completed Script range]
- Supplemental notes used only for: description / chapters / sources / tags
- Removed or unused script material: [none / list]

## Viewer-Facing Changes
| Area | Scene/Time | Change | Why It Matters For Publishing |
| --- | --- | --- | --- |
| Overlay | sc_024 | Added comparison table | Mention the practical comparison, not the original vague wording |

## Chapter And Timestamp Candidates
| Candidate Chapter | Preview Cue | Actual Time |
| --- | --- | --- |
| Opening question | First hook line appears | user fills in |

## Source And Claim Follow-Up
| Claim/Reference | Status | Notes |
| --- | --- | --- |
| [claim] | supplied / verified / needs user confirmation | [notes] |

## Publishing Notes
- Description must include:
- Description must not include:
- Hashtag/tag candidates:
```

## Before Writing The Final YouTube Draft

Check:

- The description includes only what appears in the finished video.
- Deleted script material is not reintroduced through supplemental notes.
- Added overlays, tables, examples, and video clips are reflected when important.
- Chapter names are concrete and match actual preview cues.
- Unverified sources, URLs, statistics, medical claims, and legal claims are not invented.
- YouTube Studio tag candidates are separate from the description body.
