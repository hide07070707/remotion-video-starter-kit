# Prompt Templates

## Script and Supplemental Notes Intake

Use this when the user wants to paste a completed script together with YouTube publishing support notes.

```text
これから、今回の動画制作に使う「完成台本」と「YouTube投稿準備用の補助資料」を渡します。

重要：
動画本編に使用してよいのは、下の【A. 完成台本】だけです。

【B. YouTube投稿準備用の補助資料】は、
動画本編で読み上げたり、テロップ化したりしないでください。

補助資料は、以下の目的だけに使ってください。

・動画の意図や独自性を理解する
・YouTube説明欄の最終版を作る
・チャプターを実際の動画時間に合わせて修正する
・参考文献や出典を整理する
・YouTubeタグ候補を確認する
・量産型コンテンツに見えないように確認する

動画制作中に、台本から変更した点、削除した内容、追加した図表、追加した演出、実際の章構成、タイムスタンプ候補を記録してください。

動画完成後には、補助資料の「説明欄下書き」と「仮チャプター」をもとに、
YouTube Studioへそのまま貼れる「動画説明欄の最終版」を作成してください。

【A. 完成台本】

[ここに完成台本を貼る]

【B. YouTube投稿準備用の補助資料】

[ここに補助資料を貼る]

まずは、上記の【A. 完成台本】と【B. 補助資料】を読み込み、内容を理解してください。

そのうえで、作業前に以下を確認して報告してください。

1. 動画本編として使う範囲
2. 動画本編に使ってはいけない範囲
3. この動画の中心論点
4. この動画で強調すべき具体例・判断軸・結論
5. 動画完成後に説明欄最終版へ反映すべき情報
6. 作業中に記録しておくべき変更点

まだ編集や修正は始めず、まず理解内容を確認してください。
不明な点や、台本と補助資料の境界が曖昧な点があれば、作業前に質問してください。
```

## Strict Telop Split Request

Use this prompt when the user gives a script chapter and wants the first exact telop split. This step is transcription and splitting only. Do not add image groups, scene descriptions, or creative interpretation.

If the start number, chapter range, or source text is missing, ask the user before using this prompt.

```text
命令書

あなたは、YouTube動画のテロップ制作に特化した編集者です。
下記の本文台本を、テロップとして表示する単位（シーン）に正確に分割してください。

この段階では、クリエイティブな要素を一切排除し、「正確なテキスト分割」だけを行ってください。
この工程は編集ではなく、原文を一字一句そのまま使って分割する転記作業です。

【絶対遵守ルール：原文維持】

・台本本文を、1文字たりとも省略・追加・言い換え・修正してはならない
・接続詞、助詞、語尾、句読点、記号、三点リーダ、ダッシュ、鉤括弧も含めて、全て原文のまま出力すること
・原文にない言葉を入れない
・原文にある言葉を消さない
・20文字制限に収める方法は、削ることではなく分割すること
・各シーンの字幕本文を上から順につなげたとき、今回貼った章の原文（除外対象を除く）と完全一致させること
・ただし、「---」や「----」などの区切り線のみで構成される行は、台本の構造を示す記号とみなし、シーンには含めず除外すること

【分割ルール】

・各シーンには、下記で指定する「今回の開始番号」から順に【シーン48】【シーン49】のように連番を付けること
・1シーンは最大2行まで
・1行は最大20文字まで（最重要）
・20文字を超える場合は、削らずに不自然でない位置で改行、または次のシーンへ分けること
・句読点（、）（。）があるからといって機械的に改行しない
・視覚的な読みやすさと、ナレーションとして耳に入りやすい区切りを優先する
・ただし、読みやすさを理由に原文を書き換えてはならない
・20文字以内で収まる場合は、改行せず必ず1行にまとめる

【進行ルール】

・今回貼られた章のみを出力して停止すること
・他の章には進まないこと
・章番号や見出しも、原文に含まれている場合は原文どおり扱うこと

【禁止事項】

・言い換え
・要約
・省略（区切り線を除く）
・補足
・整文
・原文順の入れ替え
・画像グループの追加
・場面説明の追加
・感情説明の追加

【出力形式】

【シーン（指定の開始番号）】
字幕本文

【シーン（連番）】
字幕本文

【シーン（連番）】
字幕本文

※必要に応じて1シーン2行まで可
※この段階では画像グループの付与は不要です
※テロップ分割のみ行ってください

【出力前チェック】

・指定した「開始番号」から正しく連番が始まっているか
・原文にない言葉が入っていないか
・原文にある言葉を消していないか
・接続詞、助詞、語尾、句読点、記号を変えていないか
・全シーンを順番につなげると、今回の章原文（区切り線除く）と完全一致するか
・20文字制限への対応として、削除や言い換えをしていないか

今回の開始番号
[ここに開始番号を入力してください（例：48）]

変換する本文台本
[ここに今回変換したい1章分だけを貼る]
```

## Combined Scene Plan And Image Group Request

Use this only after the strict telop split is approved.

Default compact request:

```text
承認済みの厳密テロップ分割をもとに、シーン計画＋画像グループ候補を作ってください。
まだmanifestは作らず、人間が確認できる表にしてください。
各グループには、画像グループID、対応シーン、場面の役割、シーン種別、制作方法、構図メモ、まとめた理由、注意点を入れてください。
原文の字幕本文は変更しないでください。
画像グループIDは3桁で付けてください。
```

Detailed direction request:

```text
命令書：YouTube動画ビジュアルディレクター（シーン計画＋画像グループ編成）

あなたは、YouTube動画のビジュアルディレクターです。

先ほど分割した「シーンリスト」を読み込み、動画としての場面設計を行ったうえで、同じ画像を使用する単位（画像グループ）に整理してください。

この段階で行うのは、「シーン計画」と「画像グループ候補の整理」です。
テキストの内容には一切手を加えず、動画化に必要な設計情報だけを追加してください。

【目的】

1. 各シーンが動画内でどんな役割を持つかを整理する
2. 各シーンを、説明・物語・感情・図解・比較・注意喚起などに分類する
3. 視聴者が飽きないよう、場面転換や演出の必要性を判断する
4. 同じ画像で成立するシーンを画像グループとしてまとめる
5. 画像生成AIで作るべき場面と、Remotionで作るべき図解・テキスト演出を分ける
6. 後工程で画像プロンプトを作りやすいよう、具体的な構図メモを付ける

【最重要ルール：原文維持】

・テキストの内容は一字一句、一切変更しないこと
・句読点、改行、表記、語尾も変更しないこと
・字幕本文の修正、要約、削除、追加は厳禁
・シーン番号は変更しない
・改行位置も変更しない
・この工程では、原文テロップに対して、シーン計画・画像グループ情報・構図メモだけを追加すること

【画像管理ルール：3桁通し番号】

・画像グループ名は必ず3桁の数字で管理すること
・例：001、002、003
・「今回の開始番号」で指定された数字からカウントを開始すること
・同じ画像で成立するシーンは積極的にまとめ、画像の枚数を増やしすぎないこと
・ただし、無理にまとめて不自然にしないこと
・視聴者が単調に感じそうな箇所では、必要に応じて画像を分けること

【シーン計画の基準】

各シーンについて、以下を判断してください。

・このシーンは何を伝える場面か
・説明シーンか、物語シーンか、感情シーンか、図解シーンか
・視聴者にどんな感情を動かしたいか
・ここで場面転換が必要か
・キャラクター演出が必要か
・図解、比較表、チェックリスト、カード表示などRemotion向きの演出が必要か
・背景画像で見せるべきか
・キャラクター＋背景で見せるべきか
・テキスト強調だけで成立するか
・後工程で手作り演出候補を追加した方がよいか

【画像グループ分けの基準】

同じグループにまとめる条件：

・場所が同じ
・時間帯が同じ
・登場人物が同じ
・動作の大枠が変わらない
・感情の流れが大きく変わらない
・見せる構図の方向性が変わらない
・同じ背景画像を使っても違和感がない

グループを分ける条件：

・場所が変わる
・時間帯が変わる
・主役人物が変わる
・大きな動作が変わる
・静から動へ切り替わる
・感情が大きく変わる
・説明から図解へ切り替わる
・構図を明らかに変えた方がよい
・同じ画像が続くと単調に見える

【制作方法の分類】

各画像グループには、制作方法を必ず付けてください。

以下から選んでください。

1. 背景生成AI
実写風・アニメ背景風・場面背景など、画像生成AIで作るべきもの。

2. キャラクター＋背景
既存キャラクター素材を背景に重ねて使うもの。

3. Remotion図解
比較表、チェックリスト、カード、矢印、グラフ、流れ図など、Remotionで作るべきもの。

4. Remotionテキスト強調
大きな文字、キーワード強調、注意喚起、短い印象文などで見せるもの。

5. 既存素材利用
すでにある背景、キャラクター、アイコンなどで成立するもの。

【ビジュアル設計・構図メモの条件】

方向性：
事前にユーザーが指定した画風に合わせる。
画風が未指定の場合は、作業前に質問する。
例：温かみのある手描き風アニメ背景、水彩絵本風、落ち着いたリアル寄り、シンプルなフラットイラスト、漫画風モノクロ、雑誌の挿絵風。
参考画像がある場合は、雰囲気・色・光・質感・構図の参考として扱う。
ただし、特定作品、既存キャラクター、ロゴ、著作物の完全再現はしない。

具体性：
以下をできるだけ明記する。

・場所
・時間帯
・室内外
・季節感
・登場人物の年齢感
・服装
・立ち位置
・視線
・表情
・動作
・カメラ距離
・構図
・光の方向
・背景小物
・画面の余白
・字幕を置きやすい場所

一貫性：
前後の画像で、人物・服装・場所・時間帯・距離感が不自然に変わらないようにする。

【出力形式】

【画像グループ001】

対応シーン：
【シーン1】〜【シーン3】

場面の役割：
この場面が動画全体で何を伝える部分かを書く。

シーン種別：
説明 / 物語 / 感情 / 図解 / 比較 / 注意喚起 / まとめ / CTA などから選ぶ。

時間：
朝 / 昼 / 夕方 / 夜 / 不明 など。

場所：
具体的な場所を書く。

登場人物：
登場人物、年齢感、服装、立ち位置を書く。

感情：
この場面で動かしたい感情を書く。

制作方法：
背景生成AI / キャラクター＋背景 / Remotion図解 / Remotionテキスト強調 / 既存素材利用

構図メモ：
画像生成やRemotion制作に使えるレベルで具体的に書く。

画像グループにまとめた理由：
なぜこの範囲を同じ画像で成立すると判断したのかを書く。

画像を分けるべき注意点：
この後どのタイミングで画像を切り替えるべきか、または単調になりそうな注意点を書く。

追加演出候補：
必要に応じて、手作り感を出すための演出候補を書く。

対応シーン：

【シーン1】【画像001】
原文テロップ

【シーン2】【画像001】
原文テロップ

今回の開始番号：
[ここに開始番号を入力してください（例：001）]

処理するシーンリスト：
[ここに前工程で出力したシーンリストを貼る]
```

## Copyable Image Prompt Request

```text
承認した画像グループごとに、外部の画像生成AIへ貼り付けられる画像プロンプトを作ってください。
各プロンプトはコピーしやすいようにコードブロックで出してください。
画像内に文字は入れないでください。
```

## Manifest Request

```text
承認済みのテロップ分割、画像グループ、画像パス、音声パスをもとにmanifestを作ってください。
既存の共通コンポーネントを壊さず、後から差し替えやすい構成にしてください。
```

## Handmade Direction Request

```text
このmanifestから、手作り演出を入れるべきシーン一覧を作ってください。
すぐ実装せず、優先順位、理由、演出案、注意点を表で提案してください。
```

## Video AI Prompt Request

```text
この画像をもとに、5秒から8秒の16:9動画を作るためのimage-to-videoプロンプトを作ってください。
文字や数字は入れず、動きは自然で控えめにしてください。
Remotionで後から字幕や図解を重ねる前提にしてください。
```

## Correction Tool Request

```text
読み間違い修正と画像差し替えをしたいので、修正サイトを開けるようにしてください。
どのファイルが変更されるかも説明してください。
```

## YouTube Publishing Draft Request

```text
動画が完成しました。

これから、YouTube投稿用の「動画説明欄の最終版」を作成してください。

重要：
以前渡した【YouTube投稿準備用の補助資料】の中にある
「説明欄下書き」「仮チャプター」「参考文献・出典メモ」「YouTubeタグ候補」を参考にしてください。

ただし、最終版は必ず、実際に完成した動画内容に合わせて修正してください。

目的：
YouTube Studioの動画説明欄に、そのままコピー＆ペーストして使える完成形を作ること。

必ず守ること：
・説明欄本文だけを出力する
・余計な解説や前置きは入れない
・本編で実際に扱った内容だけを書く
・台本にはあったが、完成動画で削除した内容は説明欄に入れない
・動画制作中に追加した図表、演出、補足内容があれば、必要に応じて反映する
・タイトル、サムネ、本編、説明欄の内容がズレないようにする
・この動画だけの論点、具体例、判断軸、結論が自然に伝わるようにする
・量産型の情報羅列に見えないよう、独自の解説意図を入れる
・キーワードの羅列や、不自然なSEO詰め込みはしない
・参考文献や出典がある場合は、「参考・出典」として整理する
・未確認の資料名やURLを勝手に作らない
・ハッシュタグは説明欄内に3〜5個入れる
・ハッシュタグは今回の動画内容に合うものにする
・YouTube Studioの「タグ」候補は、説明欄とは別に最後に出す

チャプターについて：
・完成動画の実際のタイムスタンプに合わせて作成する
・最初は必ず 0:00 から始める
・「1つ目」「2つ目」「まとめ」だけの汎用名にしない
・各チャプター名は、内容が具体的にわかる名前にする
・この動画だけの論点、具体例、判断軸、注意点、結論が見えるようにする

出力形式：

【YouTube動画説明欄・コピペ用】

ここに、YouTube Studioの説明欄へそのまま貼れる完成形を書く

--------------------------------

【YouTubeタグ候補】

ここに、YouTube Studioのタグ欄へ入れる候補を3〜5個、カンマ区切りで書く

注意：
【YouTubeタグ候補】は説明欄本文には含めません。
説明欄に貼るのは、【YouTube動画説明欄・コピペ用】の中身だけです。
```

If timestamps are not known, use this first:

```text
完成動画の正確なタイムスタンプがまだ不明な場合は、
まず「仮チャプター」ではなく、
動画内の章構成に基づいたタイムスタンプ確認リストを作ってください。

私が実際の時間を確認して入力した後、
YouTube説明欄の最終版を作成してください。
```
