# Prompt Templates

## Scene Split Request

```text
この台本を、Remotion動画用にシーン分割してください。
まだmanifestは作らず、まず人間が確認できる表にしてください。
各シーンには、仮のscene_id、本文、目的、推定秒数、画像グループ候補を入れてください。
```

## Image Group Request

```text
承認したシーン分割をもとに、画像グループを作ってください。
同じ画像で使い回せる場面と、別画像にした方がよい場面が分かるようにしてください。
まだ画像プロンプトは作らず、まず確認用の表にしてください。
```

## Copyable Image Prompt Request

```text
承認した画像グループごとに、外部の画像生成AIへ貼り付けられる画像プロンプトを作ってください。
各プロンプトはコピーしやすいようにコードブロックで出してください。
画像内に文字は入れないでください。
```

## Manifest Request

```text
承認済みのシーン分割、画像グループ、画像パス、音声パスをもとにmanifestを作ってください。
既存の共通コンポーネントを壊さず、後から差し替えやすい構成にしてください。
```

## Handmade Direction Request

```text
このmanifestから、手作り演出を入れるべきシーン一覧を作ってください。
すぐ実装せず、優先順位、理由、演出案、注意点を表で提案してください。
```

## Video AI Prompt Request

```text
この画像をもとに、5秒から8秒の16:9動画を作るためのimage-to-videoプロンプトを作ってください。
文字や数字は入れず、動きは自然で控えめにしてください。
Remotionで後から字幕や図解を重ねる前提にしてください。
```

## Correction Tool Request

```text
読み間違い修正と画像差し替えをしたいので、修正サイトを開けるようにしてください。
どのファイルが変更されるかも説明してください。
```
