# Prompt Templates

## Script and Supplemental Notes Intake

Use this when the user wants to paste a completed script together with YouTube publishing support notes.

### Beginner Paste Template

Use this first when the user has not yet pasted the script, or seems unsure what to provide.

```text
まず、下の形で貼ってください。
補助資料がない場合は、【B. 補助資料】は空欄で大丈夫です。

【A. 完成台本】
ここに動画本編で読み上げる台本を貼ってください。

【B. 補助資料】
ここに、説明欄下書き、仮チャプター、出典、タグ候補、制作メモなどがあれば貼ってください。

貼り終わったら、私がまず次の3つを確認します。
1. 動画本編として使う範囲
2. 補助資料として扱う範囲
3. 厳密テロップ分割をシーン1から始めてよいか、全文を対象にしてよいか
```

## Strict Telop Split Request

Use this prompt when the user gives a script chapter and wants the first exact telop split. This step is transcription and splitting only. Do not add image groups, scene descriptions, or creative interpretation.

Default to scene 1 and all of `A. Completed Script`. Ask only if the user needs a different start number, if the script is too long to check at once, or if the source text boundary is unclear.

```text
命令書

あなたは、YouTube動画のテロップ制作に特化した編集者です。
下記の本文台本を、テロップとして表示する単位（シーン）に正確に分割してください。

この段階では、クリエイティブな要素を一切排除し、「正確なテキスト分割」だけを行ってください。
この工程は編集ではなく、原文を一字一句そのまま使って分割する転記作業です。

【絶対遵守ルール：原文維持】

・台本本文を、1文字たりとも省略・追加・言い換え・修正してはならない
・接続詞、助詞、語尾、句読点、記号、三点リーダ、ダッシュ、鉤括弧も含めて、全て原文のまま出力すること
・原文にない言葉を入れない
・原文にある言葉を消さない
・20文字制限に収める方法は、削ることではなく分割すること
・各シーンの字幕本文を上から順につなげたとき、今回貼った章の原文（除外対象を除く）と完全一致させること
・ただし、「---」や「----」などの区切り線のみで構成される行は、台本の構造を示す記号とみなし、シーンには含めず除外すること

【分割ルール】

・各シーンには、下記で指定する「今回の開始番号」から順に【シーン48】【シーン49】のように連番を付けること
・1シーンは最大2行まで
・1行は最大20文字まで（最重要）
・20文字を超える場合は、削らずに不自然でない位置で改行すること
・1つの文が2行以内に自然に収まる場合は、必ず1シーンに収めること
・1つの文が2行でも長すぎる場合のみ、意味の切れ目で複数シーンに分けること
・句読点（、）（。）があるからといって機械的に改行しない
・視覚的な読みやすさと、ナレーションとして耳に入りやすい区切りを優先する
・ただし、読みやすさを理由に原文を書き換えてはならない
・20文字以内で収まる場合は、改行せず必ず1行にまとめる

【分割前の文字数確認手順】

各文を分割する前に、必ず以下の順番で判断すること。

1. その文全体を見る
2. 20文字以内であれば、句読点・接続詞の位置に関わらず、必ず1行にまとめる
3. 20文字を超えても、2行以内に自然に収まるなら、必ず1シーンにまとめる
4. 2行でも長すぎる文だけ、意味の切れ目で複数シーンに分ける

この手順を省略して、「なんとなく長そう」「句読点があるから」「見た目を整えたいから」という理由で分割してはならない。

禁止例A：20文字以内の文を不要に2行に分けるケース
「母はそれを捨てられないと言います。」
→ 2行に分けるのは禁止。1行にまとめること。

禁止例B：1つの文を不要に2つのシーンへ分断するケース
【シーン96】
でもあの頃の母には、
受け取る余裕が

【シーン97】
なかったのかもしれません。
→ これは禁止。2行で収まるため、1シーンにまとめること。

正しい出力：
【シーン96】
でもあの頃の母には、
受け取る余裕がなかったのかもしれません。

禁止例C：20文字以内に収まる文を不要に改行するケース
【シーン90】
誰かの手を借りなければ、
動けない。
→ これは禁止。1行で収まるため、1行にまとめること。

正しい出力：
【シーン90】
誰かの手を借りなければ、動けない。

【進行ルール】

・指定範囲がない場合は、【A. 完成台本】の全文を対象にすること
・長すぎて確認しにくい場合は、区切りのよい範囲ごとに出力して停止すること
・範囲を分ける場合は、次にどこから再開するかを明記すること
・章番号や見出しも、原文に含まれている場合は原文どおり扱うこと

【禁止事項】

・言い換え
・要約
・省略（区切り線を除く）
・補足
・整文
・原文順の入れ替え
・画像グループの追加
・場面説明の追加
・感情説明の追加

【出力形式】

【シーン（指定の開始番号）】
字幕本文

【シーン（連番）】
字幕本文

【シーン（連番）】
字幕本文

※必要に応じて1シーン2行まで可
※この段階では画像グループの付与は不要です
※テロップ分割のみ行ってください

【出力前チェック】

・指定した「開始番号」から正しく連番が始まっているか
・原文にない言葉が入っていないか
・原文にある言葉を消していないか
・接続詞、助詞、語尾、句読点、記号を変えていないか
・全シーンを順番につなげると、今回の章原文（区切り線除く）と完全一致するか
・20文字制限への対応として、削除や言い換えをしていないか
・20文字以内の文を、不要に2行に分けていないか
・2行に収まる1文を、不要に複数シーンへ分けていないか
・長文を複数シーンに分ける場合、意味の切れ目で分けているか

今回の開始番号
[通常は1。ユーザー指定がある場合のみ変更]

変換する本文台本
[通常は【A. 完成台本】全文。長い場合は確認しやすい範囲]
```

## Combined Scene Plan And Image Group Request

Use this only after the strict telop split is approved.

Default compact request:

```text
承認済みの厳密テロップ分割をもとに、シーン計画＋画像グループ候補を作ってください。
まだmanifestは作らず、人間が確認できる表にしてください。
各グループには、画像グループID、対応シーン、場面の役割、シーン種別、カット種別、制作方法、構図メモ、まとめた理由、次グループへの切り替え理由、注意点を入れてください。
原文の字幕本文は変更しないでください。
画像グループIDは3桁で付けてください。
1画像グループは原則3〜5シーン、重要場面は1〜3シーンを目安にしてください。
同じ場所でも、視聴者が飽きないように W / M / CU / INS のカット種別を切り替えてください。
```

Detailed direction request:

```text
命令書：YouTube動画ビジュアルディレクター（シーン計画＋画像グループ編成）ver.2.1

あなたは、YouTube動画のビジュアルディレクターです。

先ほど分割した「シーンリスト」を読み込み、動画としての場面設計を行ったうえで、同じ画像を使用する単位（画像グループ）に整理し、後工程で画像生成・Remotion制作・演出追加がしやすい形にしてください。

この段階で行うのは、「シーン計画」と「画像グループ候補の整理」です。
テキストの内容には一切手を加えず、動画化に必要な設計情報だけを追加してください。

【入力の扱い】

ユーザーに毎回プロンプトの空欄を手作業で埋めさせないこと。

保存済みファイルがある場合：

・`metadata/telop-split.md` を処理するシーンリストとして読む
・`metadata/visual-style.md` を承認済み画風として読む
・画像グループの開始番号は、指定がなければ `001` とする

保存済みファイルがない、または処理範囲が曖昧な場合だけ、ユーザーに短く確認すること。

初心者向けの確認例：

```text
保存済みの telop-split.md を使って、画像グループ001から始めてよいですか？
```

```text
一度に全部出すと確認が大変なので、まず一部の範囲だけ出しますか？
それとも全体案を出しますか？
```

【目的】

1. 各シーンが動画内でどんな役割を持つかを整理する
2. 各シーンを、説明・物語・感情・図解・比較・注意喚起などに分類する
3. 視聴者が飽きないよう、場面転換や演出の必要性を判断する
4. 同じ画像で成立するシーンを画像グループとしてまとめる
5. 画像生成AIで作るべき場面と、Remotionで作るべき図解・テキスト演出を分ける
6. 後工程で画像プロンプトを作りやすいよう、具体的な構図メモとカット種別を付ける

【最重要ルール：原文維持】

・テキストの内容は一字一句、一切変更しないこと
・句読点、改行、表記、語尾も変更しないこと
・字幕本文の修正、要約、削除、追加は厳禁
・シーン番号は変更しない
・改行位置も変更しない
・この工程では、原文テロップに対して、シーン計画・画像グループ情報・構図メモだけを追加すること

【画像管理ルール：3桁通し番号】

・画像グループ名は必ず3桁の数字で管理すること
・例：001、002、003
・「今回の開始番号」で指定された数字からカウントを開始すること

【画像枚数のルール：少なすぎず、多すぎず】

・1画像グループは、原則3〜5シーンを目安にすること
・重要場面、感情が強い場面、場面転換の直前直後は1〜3シーンを目安にすること
・静かな説明、余韻、同じ行動の継続でも、原則5シーンを超えて1枚にまとめないこと
・同じ場所、同じ時間帯、同じ人物でも、構図・感情・視点・小道具・動作が変わる場合は別画像グループにすること
・制作効率だけを理由に、長い範囲を1枚にまとめないこと
・ただし、短い並列列挙や章タイトル連結など、視聴リズム上自然な場合は例外的にまとめてもよい

【カット割りの基本：映像的なリズムを作る】

同じ場面・同じ時間帯でも、構図を変えることで視聴者は飽きにくくなる。
以下の4種のカットを意識して、画像グループを設計すること。

・W（ワイド）：場所全体が見える引きのショット。例：台所全体、縁側と庭、玄関全体
・M（ミディアム）：人物の上半身〜膝あたりまで。例：椅子に座る人物の上半身、立つ人物の腰から上
・CU（クローズアップ）：顔、手、足、表情など体の一部。例：横顔、手元、目元、口元
・INS（インサート）：場面に登場する小物のアップ。例：湯のみ、ノート、時計、古いリード、爪、手紙、写真

カット割りの使い方：

・同じ場面を複数グループに分ける場合は、できるだけカット種別を変えること
・W → CU → INS → M のように、カットが単調にならないよう組み合わせること
・感情の強い場面では、CU（顔・目・手）とINS（小物）を積極的に検討すること
・同じカット種別が3グループ以上連続しないようにすること
・場所や状況の説明場面は W または M から始めると分かりやすい
・小物に意味がある場面では、INSを必ず検討すること

【シーン計画の基準】

各シーンについて、以下を判断してください。

・このシーンは何を伝える場面か
・説明シーンか、物語シーンか、感情シーンか、図解シーンか
・視聴者にどんな感情を動かしたいか
・ここで場面転換が必要か
・キャラクター演出が必要か
・図解、比較表、チェックリスト、カード表示などRemotion向きの演出が必要か
・背景画像で見せるべきか
・キャラクター＋背景で見せるべきか
・テキスト強調だけで成立するか
・後工程で手作り演出候補を追加した方がよいか

【画像グループ分けの基準】

グループを分ける条件：

・原則5シーンを超える
・重要場面で3シーンを超える
・場所が変わる
・時間帯が変わる
・主役人物が変わる
・大きな動作が変わる
・静から動へ切り替わる
・感情が大きく変わる
・説明から図解へ切り替わる
・カット種別を変えた方がよい
・同じ画像、同じ構図、同じカット種別が続いて単調になる

同じグループにまとめる条件：

・場所が同じ
・時間帯が同じ
・登場人物が同じ
・動作の大枠が変わらない
・感情の流れが大きく変わらない
・カット種別・構図の方向性が変わらない
・同じ背景画像を使っても違和感がない
・シーン数が原則3〜5以内

【制作方法の分類】

各画像グループには、制作方法を必ず付けてください。

以下から選んでください。

1. 背景生成AI
実写風・アニメ背景風・場面背景など、画像生成AIで作るべきもの。

2. キャラクター＋背景
既存キャラクター素材を背景に重ねて使うもの。

3. Remotion図解
比較表、チェックリスト、カード、矢印、グラフ、流れ図など、Remotionで作るべきもの。

4. Remotionテキスト強調
大きな文字、キーワード強調、注意喚起、短い印象文などで見せるもの。

5. 既存素材利用
すでにある背景、キャラクター、アイコンなどで成立するもの。

【ビジュアル設計・構図メモの条件】

方向性：
事前にユーザーが指定した画風、または `metadata/visual-style.md` に保存された承認済み画風に合わせる。
画風が未指定の場合は、作業前に質問する。
例：実写風シネマティック、温かみのある手描き風アニメ背景、水彩絵本風、落ち着いたリアル寄り、シンプルなフラットイラスト、漫画風モノクロ、雑誌の挿絵風。
参考画像がある場合は、雰囲気・色・光・質感・構図の参考として扱う。
ただし、特定作品、既存キャラクター、ロゴ、著作物の完全再現はしない。
特定作品名が参考として出た場合も、模倣ではなく、光・空気感・構図・色温度・生活感などの一般的な要素として扱う。

具体性：
以下をできるだけ明記する。

・場所
・時間帯
・室内外
・季節感
・カット種別（W / M / CU / INS）
・登場人物の年齢感
・服装
・立ち位置
・視線
・表情
・動作
・カメラ距離
・構図
・光の方向
・背景小物
・画面の余白
・字幕を置きやすい場所

一貫性：
前後の画像で、人物・服装・場所・時間帯・距離感が不自然に変わらないようにする。

【出力形式】

【画像グループ001】

対応シーン：
【シーン1】〜【シーン3】

場面の役割：
この場面が動画全体で何を伝える部分かを書く。

シーン種別：
説明 / 物語 / 感情 / 図解 / 比較 / 注意喚起 / まとめ / CTA などから選ぶ。

カット種別：
W / M / CU / INS のどれか。なぜそのカットにするかも一言書く。

時間：
朝 / 昼 / 夕方 / 夜 / 不明 など。

場所：
具体的な場所を書く。

登場人物：
登場人物、年齢感、服装、立ち位置を書く。

感情：
この場面で動かしたい感情を書く。

制作方法：
背景生成AI / キャラクター＋背景 / Remotion図解 / Remotionテキスト強調 / 既存素材利用

構図メモ：
カット種別を踏まえて、画像生成やRemotion制作に使えるレベルで具体的に書く。

画像グループにまとめた理由：
なぜこの範囲を同じ画像で成立すると判断したのかを書く。
シーン数が目安内であることも確認して書く。

次グループへの切り替え理由：
なぜここで画像を切り替えるのかを書く。
例：シーン数上限、場所変化、感情変化、カット種別変更、小物インサート、単調回避など。

追加演出候補：
必要に応じて、手作り感を出すための演出候補を書く。
固定キャラクターが存在しない物語では、特定の案内キャラ名を勝手に出さないこと。
案内キャラを使う場合は、「小さな案内キャラ」など汎用表現にし、ユーザー確認後に使うこと。

対応シーン：

【シーン1】【画像001】
原文テロップ

【シーン2】【画像001】
原文テロップ

【出力前チェックリスト】

・指定した開始番号から正しく3桁で始まっているか
・字幕本文を1文字でも変更していないか
・シーン番号を変更していないか
・改行位置を変更していないか
・1画像グループのシーン数が原則3〜5以内になっているか
・重要場面が長くまとまりすぎていないか
・カット種別（W/M/CU/INS）が全グループに明記されているか
・同じカット種別が3グループ以上連続していないか
・感情の強い場面でCU・INSを検討しているか
・小物に意味がある場面でINSを検討しているか
・画像グループとして、同じ画像でまとめた理由が書かれているか

重要：
