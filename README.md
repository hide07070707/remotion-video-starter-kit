# Remotion Story Video Template

台本からYouTube長尺の物語・解説動画を作るための、初心者向けRemotionテンプレートです。

このリポジトリは公開共有用です。実案件の台本、完成動画、生成済み音声、生成済み動画素材、APIキーは含めていません。

## できること

- 台本を原文のまま厳密にテロップ分割して、確認しながら動画化する
- 画像グループを作り、外部画像生成AI用のプロンプトを作る
- manifestをもとにRemotionで動画を表示する
- サンプルの修正ツールで字幕・画像・音声・動画パスを確認する
- 手作り感のある演出候補をCodexに出してもらう
- 必要な場面だけ動画生成AI用プロンプトを作る

## 最初にやること

```bash
npm install
npm run start
```

Remotionのプレビューが開いたら、`StoryVideo` を選んでください。

## 修正ツール

別のターミナルで起動します。

```bash
npm run tools
```

ブラウザで開きます。

```text
http://localhost:3101/
```

このツールは最小サンプルです。実プロジェクトでは、読み間違い修正、音声再生成、画像差し替えなどを追加して使ってください。

## APIキー

`.env.example` をコピーして `.env` を作ってください。

```bash
copy .env.example .env
```

`.env` には自分のAPIキーを入れます。

重要: `.env` はGitHubに上げないでください。

## manifestとは

manifestは動画の設計図です。

サンプル:

```text
public/assets/sample-story/manifest.sample.json
```

ここに、シーンID、字幕、画像、音声、動画、表示時間を入れます。

## 新しい動画を作る流れ

1. Codexに台本を渡す
2. 厳密テロップ分割を確認する
3. シーン計画を確認する
4. 画像グループを確認する
5. 画像プロンプトをコピーできる形で作る
6. 外部画像生成AIで画像を作る
7. 画像と音声を `public/assets/your-story/` に入れる
8. manifestを作る
9. Remotionで確認する
10. 修正ツールで字幕・画像・音声を直す
11. 手作り演出候補を出す
12. 必要な場面だけ動画生成AIを使う
13. MP4を書き出す

詳しくは [docs/remotion-story-video-workflow.md](docs/remotion-story-video-workflow.md) を見てください。

## Codexに最初に言うこと

```text
新しい台本を渡します。
まず厳密テロップ分割から確認しながら進めてください。
開始番号や章の範囲で不明な点があれば、先に質問してください。
```

## 厳密テロップ分割とは

台本を、動画の字幕として表示しやすい単位に分ける作業です。

この段階では、演出や画像グループは考えません。

- 原文を一字一句変えない
- 1行20文字以内
- 1シーン最大2行
- 指定した開始番号から連番にする
- 不明点があればCodexが先に質問する

## 公開前の注意

- `.env` をGitHubに上げない
- 実案件の台本を入れない
- 完成動画を入れない
- 生成済み音声を入れない
- 生成済み動画素材を入れない
- 他人に共有できない画像素材を入れない
