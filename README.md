# Remotion Story Video Template

台本からYouTube長尺の物語・解説動画を作るための、初心者向けRemotionテンプレートです。

このリポジトリは公開共有用です。実案件の台本、完成動画、生成済み音声、生成済み動画素材、APIキーは含めていません。

## できること

- 台本を原文のまま厳密にテロップ分割して、確認しながら動画化する
- シーン計画＋画像グループ候補を作り、外部画像生成AI用のプロンプトを作る
- manifestをもとにRemotionで動画を表示する
- サンプルの修正ツールで字幕・画像・音声・動画パスを確認する
- 手作り感のある演出候補をCodexに出してもらう
- 必要な場面だけ動画生成AI用プロンプトを作る
- 補助資料をもとに、動画完成後のYouTube説明欄・チャプター・タグ候補を作る

## 最初にやること

```bash
npm install
npm run start
```

Remotionのプレビューが開いたら、`StoryVideo` を選んでください。

## 修正ツール

別のターミナルで起動します。

```bash
npm run tools
```

ブラウザで開きます。

```text
http://localhost:3101/
```

このツールは最小サンプルです。実プロジェクトでは、読み間違い修正、音声再生成、画像差し替えなどを追加して使ってください。

## APIキー

`.env.example` をコピーして `.env` を作ってください。

```bash
copy .env.example .env
```

`.env` には自分のAPIキーを入れます。

重要: `.env` はGitHubに上げないでください。

## manifestとは

manifestは動画の設計図です。

サンプル:

```text
public/assets/sample-story/manifest.sample.json
```

ここに、シーンID、字幕、画像、音声、動画、表示時間を入れます。

## 台本と補助資料を一緒に渡す場合

台本と補助資料は、同じチャットで渡しても大丈夫です。
ただし、必ず次のように分けてください。

```text
【A. 完成台本】
ここに動画本編で使う台本を入れる

【B. YouTube投稿準備用の補助資料】
ここに説明欄、仮チャプター、出典、タグ候補などの補助資料を入れる
```

動画本編に使ってよいのは `A. 完成台本` だけです。
`B. 補助資料` は、説明欄作成、チャプター調整、参考文献整理、タグ候補作成、作業中の変更点記録にだけ使います。
区切りが不明な場合、Codexは作業前に質問します。

## 新しい動画を作る流れ

1. Codexに台本と、必要なら補助資料を渡す
2. 本編に使う範囲と補助資料の範囲を確認する
3. 画風を確認する
4. 厳密テロップ分割を確認する
5. シーン計画＋画像グループ候補をまとめて確認する
6. 画像プロンプトをコピーできる形で作る
7. 外部画像生成AIで画像を作る
8. 画像と音声を `public/assets/your-story/` に入れる
9. manifestを作る
10. Remotionで確認する
11. 修正ツールで字幕・画像・音声を直す
12. 手作り演出候補を出す
13. 必要な場面だけ動画生成AIを使う
14. MP4を書き出す
15. YouTube説明欄、チャプター、タグ候補を作る

詳しくは [docs/remotion-story-video-workflow.md](docs/remotion-story-video-workflow.md) を見てください。

## Codexに最初に言うこと

```text
新しい台本を渡します。
まず厳密テロップ分割から確認しながら進めてください。
開始番号や章の範囲で不明な点があれば、先に質問してください。
```

画風を決めるとき:

```text
画風はどうしますか？
候補をいくつか出してください。
こんな感じで、という参考画像も渡せます。
```

テロップ分割を確認した後:

```text
このテロップ分割で進めてください。
次にシーン計画＋画像グループ候補を、まず確認しやすい表で出してください。
```

画像プロンプトを作るとき:

この工程では、外部画像生成AIで使うための画像プロンプトを作ります。

初心者が確認すること:

- その場面の雰囲気が伝わるか
- 同じ画像を使う範囲が長すぎないか
- 文字、矢印、チェックリストなどが画像に直接入っていないか

読ませたい文字や図解は、あとでRemotion側で重ねます。

長い動画では、画像プロンプトは一気に全部ではなく、10〜20画像グループずつ作るのがおすすめです。
まず `001〜010` を作り、確認してから `011〜020` に進むと、指示忘れや見た目のぶれを見つけやすくなります。

```text
承認済みの画像グループをもとに、
まず画像グループ001〜010の画像生成プロンプトを作成してください。
Codex内で画像生成はしないでください。
画像IDは IMG001A の形式にしてください。
コードブロック内には、外部画像生成AIに貼るプロンプトだけを書いてください。
出力後、画像内テキスト、既存キャラ再生成、Remotion重ね要素の混入がないか自己チェックし、次の範囲へ進む前に止まってください。
```

キャラクター固定やA/B案まで丁寧に作りたいとき:

```text
画像プロンプトは詳細版で作ってください。
マスターイメージ固定、参照画像の扱い、既存キャラクターのRemotion配置、画像内テキスト禁止、A/B案、Remotionで重ねる要素の分離まで含めてください。
10〜20画像グループずつ出力し、各バッチごとに確認できるようにしてください。
```

図解やチェックリストをRemotionで重ねる場面でも、背景画像は作ります。文字を重ねやすい余白を確保しつつ、テーマに合う小物、光、生活感を入れてください。

補助資料も一緒に渡す場合:

```text
完成台本と補助資料を渡します。
補助資料は本編に使わず、説明欄作成とチャプター調整用として扱ってください。
台本と補助資料の境界が不明な場合は、作業前に質問してください。
```

動画完成後に説明欄を作る場合:

```text
動画が完成しました。
完成動画の内容に合わせて、YouTube説明欄の最終版を作ってください。
正確なタイムスタンプが不明な場合は、先にタイムスタンプ確認リストを作ってください。
```

## 厳密テロップ分割とは

台本を、動画の字幕として表示しやすい単位に分ける作業です。

この段階では、演出や画像グループは考えません。

- 原文を一字一句変えない
- 1行20文字以内
- 1シーン最大2行
- 指定した開始番号から連番にする
- 不明点があればCodexが先に質問する

## 公開前の注意

- `.env` をGitHubに上げない
- 実案件の台本を入れない
- 完成動画を入れない
- 生成済み音声を入れない
- 生成済み動画素材を入れない
- 他人に共有できない画像素材を入れない
