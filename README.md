# Remotion Story Video Template

台本からYouTube長尺の物語・解説動画を作るための、初心者向けRemotionテンプレートです。

このリポジトリは公開共有用です。実案件の台本、完成動画、生成済み音声、生成済み動画素材、APIキーは含めていません。

公開用テンプレートとして使うため、実案件の素材やAPIキーはGitHubに上げないでください。
詳しくは [SECURITY.md](SECURITY.md) を確認してください。

## 利用条件

このテンプレートは、自分の動画制作に利用・改変できます。
このテンプレートを使って作成した動画の公開・収益化もできます。

ただし、テンプレート一式または改変版を、そのまま販売・再配布・教材化することは禁止します。
詳細は [LICENSE](LICENSE) を確認してください。

## 任意：制作改善を蓄積する仕組み

CodexとRemotionで出た修正・失敗・成功を記録し、次回の制作へ活かしたい方は、[友人共有用：Codex × Remotion 改善キット](friend-second-brain-kit/README.md) を利用できます。

このキットには、Obsidianの空テンプレート、改善記録、レンダリング前チェック、プロジェクト用 `AGENTS.md` テンプレートが入っています。個人情報や実案件データは含みません。利用条件は [friend-second-brain-kit/利用規約.md](friend-second-brain-kit/利用規約.md) を確認してください。

## できること

- 台本を原文のまま厳密にテロップ分割して、確認しながら動画化する
- シーン計画＋画像グループ候補を作り、外部画像生成AI用のプロンプトを作る
- 登場人物を整理し、ChatGPT image2.0、Nano Banana Pro、その他の画像生成AI用のキャラクターマスター画像プロンプトを作る
- manifestをもとにRemotionで動画を表示する
- サンプルの修正ツールで字幕・画像・音声・動画パスを確認する
- 手作り感のある演出候補をCodexに出してもらう
- 必要な場面だけ動画生成AI用プロンプトを作る
- 補助資料をもとに、動画完成後のYouTube説明欄・チャプター・タグ候補を作る

## はじめて使う人へ

このリポジトリは、Codexに案内してもらいながら使う前提です。
ターミナル操作に慣れていない場合は、自分でコマンドを打たず、Codexに次のように頼んでください。

```text
このGitHubリポジトリを使って、Remotion物語動画テンプレートを動かしたいです。
READMEを読んで、必要な環境確認、npm install、プレビュー起動まで案内してください。
私は初心者なので、コマンドを実行する前に何をするか説明してください。
```

## 必要なもの

- Codexを使える環境
- GitHubからこのリポジトリを取得できる環境
- Node.js 18以上
- npm

Remotionは、このリポジトリの依存関係に含まれています。
別途Remotionを先に入れておく必要はありません。

Node.jsが入っているか分からない場合は、Codexにこう聞いてください。

```text
Node.jsとnpmが入っているか確認してください。
入っていない場合は、インストール方法を初心者向けに案内してください。
```

## GitHubから取得した後の流れ

1. GitHubからこのリポジトリを取得する
2. Codexでこのフォルダを開く
3. CodexにREADMEを読んでもらう
4. `npm install` で必要なものを入れる
5. `npm run start` でRemotionプレビューを開く
6. プレビューで `StoryVideo` を選ぶ

Codexには、次のように頼むと進めやすいです。

```text
このフォルダを確認して、READMEの手順どおりに初期セットアップを進めてください。
まず必要なものが入っているか確認し、問題なければ npm install から進めてください。
```

## 最初にやるコマンド

```bash
npm install
npm run start
```

`npm install` は、RemotionやReactなど、このテンプレートに必要なものを入れるコマンドです。
`npm run start` は、Remotionのプレビュー画面を開くコマンドです。

Remotionのプレビューが開いたら、`StoryVideo` を選んでください。

```bash
npm run tools
```

```text
http://localhost:3101/
```

このツールは最小サンプルです。実プロジェクトでは、読み間違い修正、音声再生成、画像差し替えなどを追加して使ってください。

`.env.example` をコピーして `.env` を作ってください。

Windowsの場合:

```bash
copy .env.example .env
```

Mac/Linuxの場合:

```bash
cp .env.example .env
```

`.env` には自分のAPIキーを入れます。

重要: `.env` はGitHubに上げないでください。

## GitHubに公開するときの注意

このテンプレートを自分のGitHubで公開・共有する前に、次を確認してください。

```bash
git status --short
npm run test
```

公開してはいけないもの:

- `.env`
- APIキー、トークン、パスワード
- 実案件の台本や補助資料
- 生成済み音声、動画、画像
- 完成MP4
- 公開前のYouTube説明欄や出典メモ

このリポジトリでは、実案件で作られやすい次のフォルダを `.gitignore` で無視しています。

```text
public/assets/<story>/metadata/
public/assets/<story>/prompts/
public/assets/<story>/inbox/
public/assets/<story>/audio/
public/assets/<story>/videos/
public/assets/<story>/images/
```

もし誤ってAPIキーや実案件素材をコミットした場合は、削除コミットだけでは不十分です。
APIキーはすぐに無効化・再発行し、Git履歴からも消してから公開してください。

## manifestとは

manifestは動画の設計図です。

サンプル:

```text
public/assets/sample-story/manifest.sample.json
```

ここに、シーンID、字幕、画像、音声、動画、表示時間を入れます。

## 台本と補助資料を一緒に渡す場合

台本と補助資料は、同じチャットで渡しても大丈夫です。
ただし、必ず次のように分けてください。

```text
【A. 完成台本】
ここに動画本編で使う台本を入れる

【B. YouTube投稿準備用の補助資料】
ここに説明欄、仮チャプター、出典、タグ候補などの補助資料を入れる
```

動画本編に使ってよいのは `A. 完成台本` だけです。
`B. 補助資料` は、説明欄作成、チャプター調整、参考文献整理、タグ候補作成、作業中の変更点記録にだけ使います。
区切りが不明な場合、Codexは作業前に質問します。

貼り付けた台本と補助資料は、後から参照できるように保存します。

```text
public/assets/your-story/metadata/source-script.md
public/assets/your-story/metadata/supplemental-notes.md
```

厳密テロップ分割では、チャット欄ではなく保存した `source-script.md` を基準にします。

後工程で使う大事なものも、チャット欄だけに置かず保存します。

```text
public/assets/your-story/metadata/telop-split.md
public/assets/your-story/metadata/visual-style.md
public/assets/your-story/metadata/scene-plan-image-groups.md
public/assets/your-story/metadata/characters.md
public/assets/your-story/prompts/character-master-prompts.md
public/assets/your-story/inbox/characters/
public/assets/your-story/images/characters/CHAR001_MASTER.png
public/assets/your-story/inbox/images/
public/assets/your-story/prompts/image-groups-001-010.md
public/assets/your-story/metadata/asset-map.md
public/assets/your-story/metadata/production-log.md
```

Codexは、各確認ポイントで承認された内容を保存してから次へ進みます。

## 新しい動画を作る流れ

1. Codexに台本と、必要なら補助資料を渡す
2. 本編に使う範囲と補助資料の範囲を確認する
3. 厳密テロップ分割を確認する
4. 画風を確認する
5. シーン計画＋画像グループ候補をまとめて確認する
6. 必要な人物のキャラクターマスター画像用プロンプトを作る
7. 外部画像生成AIでキャラクターマスター画像を作る
8. マスター画像を参照しながら、画像プロンプトをコピーできる形で作る
9. 外部画像生成AIで画像を作る
10. 画像と音声を `public/assets/your-story/` に入れる
11. manifestを作る
12. Remotionで確認する
13. 修正ツールで字幕・画像・音声を直す
14. 手作り演出候補を出す
15. 必要な場面だけ動画生成AIを使う
16. MP4を書き出す
17. YouTube説明欄、チャプター、タグ候補を作る

制作中に、台本から削った内容、追加した図表や演出、差し替えた動画素材、実際のチャプター候補は短く記録しておくと、最後の説明欄が完成動画とズレにくくなります。

詳しくは [docs/remotion-story-video-workflow.md](docs/remotion-story-video-workflow.md) を見てください。

## Codexに最初に言うこと

```text
新しい台本を渡します。
まず厳密テロップ分割から確認しながら進めてください。
通常はシーン1から、【A. 完成台本】の全文を対象にしてください。
長い場合は、確認しやすい範囲に分けて進めてください。
```

Codexから台本の貼り方を聞かれたら、下の形で貼るのが一番簡単です。

```text
【A. 完成台本】
ここに動画本編で読み上げる台本を貼る

【B. 補助資料】
ここに説明欄下書き、仮チャプター、出典、タグ候補などを貼る
補助資料がなければ空欄でOK
```

テロップ分割を確認した後、画風を決めるとき:

```text
次にシーン計画＋画像グループ候補を作るため、
画風はどうしますか？
候補をいくつか出してください。
こんな感じで、という参考画像も渡せます。
```

テロップ分割を確認した後:

```text
このテロップ分割で進めてください。
次にシーン計画＋画像グループ候補を、まず確認しやすい表で出してください。
```

キャラクターマスター画像を作るとき:

```text
承認済みのシーン計画＋画像グループ候補をもとに、
登場人物を整理して、必要なキャラクターマスター画像用プロンプトを作ってください。
すでに選んだ画風を自動で反映してください。
画像生成AI用プロンプトは、ChatGPT image2.0 用、Nano Banana Pro 用、その他から選べるようにしてください。
```

外部画像生成AIでキャラクターマスター画像を作ったら、Codexが受け取り用フォルダを開きます。
ユーザーは、開いたフォルダへ画像をドラッグ＆ドロップするだけです。

```text
public/assets/your-story/inbox/characters/
```

ファイル名はそのままで大丈夫です。
入れ終わったら、Codexにこう伝えます。

```text
入れました
```

Codexが確認して、必要に応じて次のような名前へ整理します。

```text
CHAR001_MASTER.png
CHAR002_MASTER.png
```

画像プロンプトを作るとき:

この工程では、外部画像生成AIで使うための画像プロンプトを作ります。

初心者が確認すること:

- その場面の雰囲気が伝わるか
- 同じ画像を使う範囲が長すぎないか
- 文字、矢印、チェックリストなどが画像に直接入っていないか

読ませたい文字や図解は、あとでRemotion側で重ねます。

長い動画では、画像プロンプトは一気に全部ではなく、10〜20画像グループずつ作るのがおすすめです。
まず `001〜010` を作り、確認してから `011〜020` に進むと、指示忘れや見た目のぶれを見つけやすくなります。
画像生成は、各バッチ確認後にすぐ行っても、全プロンプトが揃ってからまとめて行っても大丈夫です。

```text
承認済みの画像グループをもとに、
まず画像グループ001〜010の画像生成プロンプトを作成してください。
Codex内で画像生成はしないでください。
画像IDは img_001 の形式にしてください。
A/B案がある場合は img_001_A、img_001_B の形式にしてください。
各画像グループには、保存名も書いてください。
コードブロック内には、外部画像生成AIに貼るプロンプトだけを書いてください。
出力後、画像内テキスト、既存キャラ再生成、Remotion重ね要素の混入がないか自己チェックし、次の範囲へ進む前に止まってください。
```

Codexは各バッチの後に、こう案内します。

```text
まず画像グループ001〜010の画像プロンプトを出しました。
確認してください。

次の範囲へ進む場合は「011〜020へ進んで」と言ってください。
```

外部画像生成AIで画像を作った後は、Codexが受け取り用フォルダを開きます。
作った画像をドラッグ＆ドロップしてください。

```text
public/assets/your-story/inbox/images/001-010/
```

このフォルダには、画像グループ001〜010の画像だけを入れます。
ダウンロード名が数字の羅列になる場合は、できるだけプロンプトに書かれている保存名へ変えてください。

```text
img_001.png
img_002.png
```

完全に同じ名前でなくても、画像IDが分かれば大丈夫です。

```text
img_001(2).png
img_001_修正版.png
img_002_candidate.png
```

A/B案を両方残す場合は、次のようにします。

```text
img_001_A.png
img_001_B.png
```

Codexが確認後、最終的なファイル名へ整えます。
画像IDが分からない名前のままになっている場合だけ、どのファイルがどの画像IDか分かる簡単なメモを一緒に渡してください。
入れ終わったら、Codexにこう伝えます。

```text
001〜010を入れました
```

キャラクター固定やA/B案まで丁寧に作りたいとき:

```text
画像プロンプトは詳細版で作ってください。
マスターイメージ固定、参照画像の扱い、既存キャラクターのRemotion配置、画像内テキスト禁止、A/B案、Remotionで重ねる要素の分離まで含めてください。
10〜20画像グループずつ出力し、各バッチごとに確認できるようにしてください。
```

図解やチェックリストをRemotionで重ねる場面でも、背景画像は作ります。文字を重ねやすい余白を確保しつつ、テーマに合う小物、光、生活感を入れてください。

補助資料も一緒に渡す場合:

```text
完成台本と補助資料を渡します。
補助資料は本編に使わず、説明欄作成とチャプター調整用として扱ってください。
台本と補助資料の境界が不明な場合は、作業前に質問してください。
```

動画完成後に説明欄を作る場合:

```text
動画が完成しました。
完成動画の内容に合わせて、YouTube説明欄の最終版を作ってください。
正確なタイムスタンプが不明な場合は、先にタイムスタンプ確認リストを作ってください。
```

## 厳密テロップ分割とは

台本を、動画の字幕として表示しやすい単位に分ける作業です。

この段階では、演出や画像グループは考えません。

承認したテロップ分割は、次のファイルに保存します。

```text
public/assets/your-story/metadata/telop-split.md
```

このファイルはMarkdownなので、手作業で修正できます。
修正した後は、Codexにこう伝えてください。

```text
telop-split.md を手作業で修正しました。
source-script.md と照合して、原文が変わっていないか確認してください。
問題なければ次の工程へ進んでください。
```

- 原文を一字一句変えない
- 1行20文字以内
- 1シーン最大2行
- まず1文全体を見る
- 20文字以内の文は、句読点があっても1行にまとめる
- 20文字を超えても2行以内に自然に収まる文は、1シーンにまとめる
- 2行でも長すぎる文だけ、意味の切れ目で複数シーンに分ける
- 「なんとなく長そう」「句読点があるから」「見た目を整えたいから」という理由だけで分割しない
- 指定した開始番号から連番にする
- 通常はシーン1から始める
- 通常は【A. 完成台本】の全文を対象にする
- 長い場合は確認しやすい範囲に分ける
- 不明点があればCodexが先に質問する

例:

```text
誰かの手を借りなければ、動けない。
```

このように1行で収まる文は、途中で改行しません。

```text
でもあの頃の母には、
受け取る余裕がなかったのかもしれません。
```

このように2行で収まる文は、別シーンに分けません。
