# 友人共有用：Codex × Remotion 改善キット

Remotionでの動画制作中に出た修正・失敗・成功を記録し、次回のCodex作業で同じ問題を減らすための空テンプレートです。

個人のObsidian保管庫、実案件の素材、APIキー、購入教材の本文は含みません。

## 導入方法

1. この `friend-second-brain-kit` フォルダを自分のPCへコピーします。
2. `templates/obsidian` をObsidianで新しい保管庫として開きます。
3. `templates/AGENTS.template.md` を、Remotionプロジェクト直下の `AGENTS.md` としてコピーします。
4. `YOUR_SECOND_BRAIN_PATH` を、自分のObsidian保管庫の絶対パスへ置き換えます。

## 日常の使い方

1. 制作中に直した内容を、改善記録テンプレートで残します。
2. 複数回使う・影響が大きいものだけを共通制作ルールへ昇格します。
3. 次回Codexに作業を頼むときは、関連するルールと改善ログを確認させます。
4. ルール更新は、内容を確認してから行います。

## フォルダの役割

- `00_システム`：Codexに守らせる共通制作ルール
- `01_プロジェクト`：作品ごとの制作メモとレビュー
- `03_知識ベース`：改善ログ、エラーと解決策、品質の学び

詳しい利用条件は [利用規約.md](利用規約.md) を確認してください。
