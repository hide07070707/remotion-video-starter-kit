`YOUR_SECOND_BRAIN_PATH`

For non-trivial Remotion production, repair, or rendering work:

1. Read `00_システム/Remotion制作ルール/01_共通制作ルール.md` and `03_レンダリング前チェック.md`.
2. Read only the improvement notes relevant to the current task.
3. Preserve applicable rules unless the user asks to change them.
4. After the work, report a reusable improvement-record candidate: what happened, why, how it was fixed, and how to prevent it next time.
5. Do not update long-term rules or logs without the user's approval.
